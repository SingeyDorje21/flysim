# Bug Report

## Summary
Escape does nothing on the Flight School screen, although it returns to the main menu from the "Choose a mode" (Fly) screen.

## Classification
- **Category**: UI
- **System**: Global hotkeys (`src/input/hotkeys.ts`)
- **Frequency**: Always
- **Regression**: Unknown (the Flight School screen was added after the hotkey handler)
- **Status**: Fixed, verified

## Environment
- **Build**: 4a262c5 + fix
- **Platform**: Windows 11, Chromium (Claude browser pane), Vite dev server
- **Scene/Level**: Main menu → Flight School

## Reproduction Steps
1. Open the main menu.
2. Click **Flight School**.
3. Press Escape.

**Expected**: back to the main menu, as from the Fly screen.
**Actual**: nothing happens; only the Back button works.

## Technical Context
- **Likely affected files**: `src/input/hotkeys.ts`
- **Root cause**: `handleHotkey` only mapped Escape to `goToMainMenu()` for the `modeSelect` screen.
- **Fix**: also handle the `flightSchool` screen.

## Evidence
- Browser run before the fix: heading "Flight School" before and after Escape. After the fix: "Flight School" → "FlySim".
- Regression tests: `src/input/__tests__/hotkeys.test.ts` (first tests for `handleHotkey`).
